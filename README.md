# ricardo-portfolio-api
REST API for my professional portfolio built with Node.js, Express, TypeScript and MongoDB.

## Development Scripts

The following npm scripts are available for local development and code-quality validation:

| Command | Description |
| --- | --- |
| `npm run dev` | Starts the development server with automatic reload using `tsx`. |
| `npm run build` | Compiles the TypeScript source code into the `dist/` directory. |
| `npm run type-check` | Runs the TypeScript compiler without generating output files. |
| `npm run lint` | Analyzes the TypeScript source code with ESLint. |
| `npm run format` | Formats the TypeScript source code with Prettier. |
| `npm run format:check` | Checks that the source code follows the configured Prettier rules without modifying files. |
| `npm start` | Starts the compiled application from `dist/server.js`. |
